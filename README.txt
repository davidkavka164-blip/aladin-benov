ALADIN METEOGRAM – BEŇOV (pracovní verze 0.4)
Lokalita: 49.417362 N, 17.501343 E.
Předpověď využívá Open-Meteo CHMI Aladin Seamless, 7 dní, timezone Europe/Prague.
První 3 dny: ČHMÚ ALADIN; další dny: ECMWF IFS HRES.
Pět grafů: teplota; vítr; srážky a relativní vlhkost; tlak; oblačnost.
Aplikace se aktualizuje každých 30 minut a umožňuje ruční aktualizaci.
Při výpadku API zobrazí poslední uložená data s upozorněním, případně chybovou zprávu.
Hostování musí být přes HTTPS. Android: Chrome > Instalovat aplikaci. iPhone: Safari > Sdílet > Přidat na plochu.
Zdroj: Open-Meteo CHMI Aladin API. Neoficiální nezávislé zobrazení.
